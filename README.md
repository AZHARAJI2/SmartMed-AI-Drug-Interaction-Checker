# 💊 نظام فحص تفاعلات الأدوية بالذكاء الاصطناعي

> **Drug Package Image Interaction Checker**
>
> نظام ذكي يتعرف على الأدوية من صور العبوات باستخدام تقنيات الرؤية الحاسوبية والتعلم العميق،
> ثم يفحص التفاعلات الدوائية الخطيرة بينها تلقائياً عبر قاعدة بيانات DDInter العالمية.

---

## 📋 نظرة عامة

يوفر النظام حلاً متكاملاً لمشكلة التفاعلات الدوائية الخطيرة من خلال:

1. **التعرف على الأدوية من الصور** — مساران متوازيان:
   - **مسار OCR**: قراءة النص من صورة العبوة باستخدام EasyOCR
   - **مسار التصنيف**: تصنيف الصورة بالتعلم العميق (MobileNetV3 Transfer Learning)
   - **دمج النتائج**: خوارزمية Fusion تدمج المسارين للحصول على أعلى دقة

2. **فحص التفاعلات الدوائية** — محرك ذكي يقارن الأدوية بقاعدة بيانات DDInter (أكثر من 160,000 تفاعل مسجل) ويصنف النتيجة إلى:
   - 🟢 **آمن** — لا توجد تفاعلات خطيرة
   - 🟡 **تحذير** — يُنصح بالحذر والمتابعة
   - 🔴 **خطر** — تفاعل خطير يستدعي تدخل الطبيب

3. **واجهة مستخدم ثنائية** — صفحة للمريض وأخرى للصيدلاني

## 🛠️ التقنيات المستخدمة

| التقنية | الاستخدام |
|---|---|
| **PyTorch** | التعلم العميق (Transfer Learning - MobileNetV3) |
| **EasyOCR** | قراءة النص من صور العبوات |
| **OpenCV** | معالجة الصور (CLAHE, Sharpening, Quality Gate) |
| **FastAPI** | واجهة برمجة التطبيقات الخلفية (REST API) |
| **SQLAlchemy + SQLite** | قاعدة البيانات (الأدوية، المكونات، التفاعلات، المستخدمين) |
| **Streamlit** | واجهة المستخدم الأمامية |
| **ReportLab** | توليد التقارير الطبية بصيغة PDF (عربي) |
| **Pydantic** | التحقق من صحة البيانات |
| **JWT + Bcrypt** | المصادقة وتشفير كلمات المرور |
| **pytest** | الاختبارات الآلية |

## ⚙️ التثبيت والتشغيل

### المتطلبات الأساسية
- Python 3.12+
- Windows (تم التطوير والاختبار على Windows)

### خطوات التثبيت

```bash
# 1. استنساخ المشروع
git clone <repository-url>
cd DL_IM_Project

# 2. إنشاء بيئة افتراضية
python -m venv .venv
.venv\Scripts\activate

# 3. تثبيت المتطلبات
pip install -r requirements.txt

# 4. بناء قاعدة البيانات (استيعاب بيانات DDInter)
python scripts/ingest_ddinter.py

# 5. إضافة الأسماء البديلة الشائعة للأدوية
python scripts/seed_aliases.py
```

### التشغيل

```bash
# تشغيل الخادم الخلفي (API)
uvicorn main:app --reload
# أو
python main.py

# تشغيل واجهة المستخدم (في طرفية منفصلة)
streamlit run ui/app.py

# تشغيل الاختبارات
python -m pytest tests -q
```

- **واجهة API + Swagger**: http://127.0.0.1:8000/docs
- **واجهة Streamlit**: http://localhost:8501

## 👥 واجهات النظام

### صفحة المريض 🧑‍⚕️
- تسجيل حساب وتسجيل دخول (JWT)
- إضافة الأدوية بالاسم مباشرة أو بالبحث في القاعدة
- تصوير عبوة الدواء بالكاميرا أو رفع صورة ← التعرف التلقائي
- فحص التعارض الدوائي التلقائي عند وجود دوائين أو أكثر
- تحميل تقرير طبي بصيغة PDF باللغة العربية
- سجل الفحوصات السابقة

### صفحة الصيدلاني 💊
- فحص فوري للتعارض بين أدوية متعددة (سلة فحص)
- إضافة الأدوية بالاسم المباشر أو بالبحث أو دفعة واحدة
- مسح صورة العبوة مع معاينة الشرح البصري (Visual Explainability)
- مراجعة وتصحيح نتائج التعرف ← تعليم النظام (Correction Learning)
- عرض آخر الفحوصات

## 🔬 خط سير العمل (Pipeline)

```
صورة العبوة
    │
    ├── فحص الجودة (دقة، وضوح، إضاءة)
    │       │
    │       ├── مرفوضة ← رسالة خطأ
    │       └── مقبولة ↓
    │
    ├── تحسين الصورة (CLAHE + Sharpening)
    │
    ├── مسار 1: OCR (EasyOCR) ← اسم من النص
    ├── مسار 2: تصنيف (MobileNetV3) ← اسم من الصورة
    │
    ├── دمج النتائج (Fusion Strategy)
    │       ├── متفق ← ثقة عالية
    │       ├── مختلف ← "غير مؤكد"
    │       └── أحدهما فارغ ← الآخر يُعتمد
    │
    ├── مطابقة الدواء في قاعدة البيانات (Fuzzy Matching)
    │
    ├── فحص التفاعلات الدوائية (DDInter Engine)
    │       └── آمن / تحذير / خطر
    │
    └── الشرح البصري (Visual Explainability Overlay)
```

## 📁 قواعد البيانات

### DDInter (Drug-Drug Interactions)
- **المصدر**: [DDInter Database](http://ddinter.scbdd.com/)
- **الحجم**: أكثر من 160,000 تفاعل دوائي مسجل
- **الملفات**: 8 ملفات CSV في مجلد `ddinter_database/`
- **الاستخدام**: مرجع فحص التفاعلات الدوائية

### قاعدة بيانات الأدوية اليمنية
- **الملفات**: `yemen_drug_database/yemen_global_drugs_500.csv`
- **الصور**: صور عبوات أدوية في `yemen_drug_database/images/`
- **الاستخدام**: تدريب نموذج التصنيف
